# Hi! 👋🏼 I'm Cesar Meza Carrillo

### 💻 Fullstack Developer & Forward Deployed Engineer

I build software and deploy it where it has to work: inside client environments. 5+ years as a Fullstack Developer embedded with global enterprise clients (gaming, e-learning, telecom, healthcare) through NTT Data, TCS and Encora, backed by 20+ years in IT, from rolling out a full plant network for Mercedes-Benz to production React/Node.js apps and AI-assisted workflows.

- 🎯 Frontend architecture with **React, Next.js, Vue and TypeScript**, specialized in **web accessibility (WCAG, ARIA)**
- ⚙️ Backend & data: **Node.js/Express, Python, REST & GraphQL APIs, PostgreSQL, Redis**
- 🚀 Deployment: **AWS, Docker, Dokploy, Vercel** and self-hosted Linux infrastructure
- 🤖 AI-assisted development: **Claude Code, GitHub Copilot, Cursor, Codex** · OpenAI-certified
